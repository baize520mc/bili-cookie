# BiliCookie — B站 Cookie 管理插件

> 本 README 由 AI 辅助生成，内容依据项目源码整理，如有出入以实际功能为准。

一个运行于 [Halo 2.26+](https://halo.run) 平台的插件，为 Halo 用户提供 **Bilibili Cookie 的安全保存、自动续期与自助管理** 能力。用户可将 B 站 Cookie 加密托管到本站，由插件按时自动刷新避免失效；支持专属客户端连接，实现 B 站账号自动登录。

## 功能特性

### 用户端（用户中心 →「B站 Cookie」）

- **加密托管**：Cookie 敏感字段（SESSDATA、bili_jct、DedeUserID、refresh_token 等）以 **AES-256-GCM** 加密后存储，仅本人可见。
- **一键自动续期**：复刻 B 站官方 6 步刷新协议（预热 → 取时间戳 → RSA 生成路径 → 提取 refresh_csrf → 刷新 → 作废旧 token），到达刷新间隔后由插件自动续期，避免 Cookie 过期。
- **手动刷新**：随时手动触发刷新，成功后自动回填新凭据。
- **有效性验证**：调用 B 站接口校验 Cookie，并抓取 B 站用户名与 UID 展示。
- **状态概览**：剩余有效期、上次刷新时间、全局开关、自动续期状态一目了然。
- **三级用户开关**：
  - 插件功能总开关（控制保存 / 更新 / 读取 / 验证等全部功能）
  - 接受客户端连接（允许专属客户端读取 Cookie，不影响本站页面使用）
  - 自动刷新 Cookie（到达间隔由本站自动续期）
- **脱敏展示**：查看 Cookie 时仅显示首尾 4 位，完整内容不落地前端。
- **操作日志**：本人所有操作（保存 / 刷新 / 验证 / 客户端连接）均可回溯。
- **清除数据**：一键删除全部数据并禁用，二次确认，不可恢复。

### 管理端（系统 →「Cookie 管理日志」）

- **全局设置**：全局开关、刷新间隔（小时）、Cookie 预估有效期（天）。
- **系统概览**：全局开关状态与已配置用户总数。
- **用户列表**：查看每个用户的配置状态、有效期、B 站账号与开关状态。
- **代管操作**：管理员可代用户保存、删除、刷新 Cookie。
- **全局操作日志**：聚合用户操作与管理员操作，支持按用户 ID 筛选。

### 安全与权限

- 敏感数据全链路加密存储（AES-256-GCM，密钥独立保管）。
- UI 一律脱敏展示 Cookie，明文仅在服务端内部链路使用。
- RBAC 双角色：`view` 角色聚合到 `authenticated`（所有登录用户可自助使用）；`manage` 角色独立授权，仅超级管理员或获授「Cookie 管理」角色的用户可访问管理接口。
- 定时清理孤儿 Cookie（用户已删除但数据残留）。
- 全量审计日志，失败操作同样留痕。

## 安装

1. 下载插件 JAR 包（`bili-cookie-*.jar`）。
2. 进入 Halo 后台：**插件 → 安装**，上传 JAR 并启用。
3. 启用后在 **用户中心 →「B站 Cookie」** 页面开启「插件功能总开关」，并上传你的 B 站 Cookie。

> 环境要求：Halo ≥ 2.26.0，Java 21。

## 使用说明

### 获取 B 站 Cookie（5 个字段）

在「更新 Cookie」弹窗中需一次性填写以下字段：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `SESSDATA` | ✅ | 登录凭证，最重要 |
| `bili_jct` | ✅ | CSRF Token，刷新与验证必需 |
| `DedeUserID` | ✅ | 用户 UID |
| `refresh_token` | ✅ | 刷新令牌，自动续期依赖（缺失则无法自动刷新） |
| `sid` | ❌ | 会话 ID，可选项 |

> 提示：为保证自动续期可用，请在浏览器登录态中**同一次会话**内一次性抓取全部 5 个字段，避免 `refresh_token` 与 Cookie 不匹配（B 站错误码 86095）。

### 用户端流程

1. 开启「插件功能总开关」。
2. 点击右上角「更新 Cookie」，填写字段并确认。
3. 保存后插件自动抓取 B 站账号信息，页面展示账号与剩余有效期。
4. 可按需开启「接受客户端连接」「自动刷新 Cookie」。
5. 到期前可点「手动刷新」或依赖定时自动续期。

### 管理端流程

1. 超级管理员或已授权「Cookie 管理」角色的用户可进入 **系统 →「Cookie 管理日志」**。
2. 在插件设置中调整全局开关、刷新间隔与预估有效期。
3. 通过日志页按用户筛选查看全局操作记录。

## 技术架构

```
┌─────────────────────────────────────────────────────┐
│                      B 站 API                         │
│   passport.bilibili.com / api.bilibili.com           │
└──────────────────────┬──────────────────────────────┘
                       │ HTTP (WebClient, gzip, 超时)
┌──────────────────────▼──────────────────────────────┐
│  bili-cookie 插件（Java 21 + Spring WebFlux）         │
│                                                      │
│  BiliRefreshService   ─ 6 步自动续期协议               │
│  BiliAccountService   ─ 账号验证 / 信息抓取            │
│  BiliCookieService    ─ Cookie 业务 + AES 加解密       │
│  BiliCookieRefreshScheduler ─ 定时扫描自动刷新         │
│  AuditLogService      ─ 全量审计日志                   │
│  AdminService         ─ 管理端业务                     │
└──────────────────────┬──────────────────────────────┘
                       │ REST (Reactive API)
┌──────────────────────▼──────────────────────────────┐
│  用户中心 Vue 页面  │  管理端 Vue 页面                 │
│  CookieManageView   │  AdminLogsView                 │
└─────────────────────────────────────────────────────┘
```

- 后端：Java 21、Spring WebFlux（Reactor）、Halo 2.26 插件 API
- 存储：Halo Extension 自定义模型（`BiliCookie`），敏感字段密文存储
- 前端：Vue 3 + TypeScript + Vite，基于 `@halo-dev/components` / FormKit
- 构建：Gradle 8 + `ui-plugin-bundler-kit`
